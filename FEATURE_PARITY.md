# RupeeLens feature parity

This checklist maps every useful workflow from the three source applications into RupeeLens.

## Transaction intelligence

- [x] Configurable synthetic transaction generator
- [x] Dashboard KPIs and amount, hour, location, type, and bank breakdowns
- [x] Single-transaction risk analysis
- [x] Fraud/routine presets and session history
- [x] CSV template, batch analysis, and result export
- [x] Filterable data explorer with CSV export
- [x] Random-Forest-style and gradient-boosting-style score comparison
- [x] Confusion matrix, precision, recall, F1, ROC/AUC, and feature importance

## Security log analysis

- [x] Five log families: login, session, authentication, request, and service
- [x] Configurable deterministic synthetic-log generation
- [x] Independent CSV upload for all five log families
- [x] Composite risk score and anomaly queue
- [x] Overview charts and log-family drill-downs
- [x] Brute-force, abnormal-session, credential-stuffing, request-flood, and suspended-service detection
- [x] Search and severity/category filters
- [x] Per-family CSV export and downloadable text report

## Budget analytics

- [x] Historical five-ministry dataset for FY2014–15 through FY2024–25
- [x] Official FY2026–27 headline figures and per-rupee maps
- [x] Dashboard year range, Finance-outlier control, log scale, trends, shares, and YoY heatmap
- [x] Ministry drill-down with revenue/capital and Plan/Non-Plan treatment
- [x] Linear and polynomial forecasts, confidence bands, and model comparison
- [x] Multi-ministry absolute, indexed, YoY, and budget-share comparisons
- [x] Smart Query patterns and presets
- [x] Custom budget CSV upload
- [x] Raw, yearly-summary, ministry-summary, pivot, and spreadsheet exports
